2026 KBO 정보 시각화 사이트: 수업 발표용 인터랙티브 초안

실행:
1. 압축을 풉니다.
2. index.html을 Chrome, Safari, Edge 같은 브라우저로 엽니다.
3. 최초 진입 시 (교체 전) 인트로 만화가 표시됩니다. My Team을 선택한 뒤 '기록 확인'을 누르세요.

현재 구현:
- 시즌 순위, My Team, 선택한 구단 행 아래 펼치는 상세 지표
- 레이더/불릿/영역 차트 및 선수 TOP 3
- 홈런 방향·비거리 근사 배치 및 번호 있는 야구공 마커, 클릭·호버 정보
- 투수 공통 구종 움직임 예시, 시점 전환, 구종 토글, 도넛 차트
- 팀 VS 팀 비교, 맞대결 예시, 이닝별 예시 스코어보드
- 선수 검색/구단 필터/기록별 정렬/3열↔4열/카드 뒤집기/선수 상세 페이지
- 반응형 모바일 레이아웃, 우측 하단 맨 위 이동 버튼

주의:
- 모든 수치, 순위, 경기, 선수 이름, 홈런 날짜·구장·속도·발사각, 구종 비율은 자동 생성한 '시연용 임시 데이터'이며 2026년 실제 KBO 기록이 아닙니다.
- 구단 이름은 실제 명칭이지만 순서는 실제 순위가 아닙니다.
- 엠블럼은 아직 정식 이미지가 아닌 텍스트 로고 대체품입니다.
- 사이트 이름, 인트로 만화, 캐릭터, 선수 사진은 모두 (교체 전) 상태입니다.
- 홈런 위치는 각 방향 및 임시 비거리에 따라 시각적으로 배치합니다. 정확한 착지점이 아닙니다.
- 투구 궤적은 구종별 공통 설명용 애니메이션입니다.
- 공식 수치와 이미지/로고를 연결하기 전, 자료 이용 허락과 출처를 확인해 주세요.
